# Contributing to editor.izdrail.com

Bug reports, feature requests and pull requests are welcome through
[GitHub issues](https://github.com/izdrail/editor.izdrail.com/issues) and pull
requests on this repository.

* **Bugs**: open an issue with the steps to reproduce, your OS and the editor version.
* **Features**: open an issue first so the approach can be agreed before you write code.
* **Code**: build as described in [docs/building-from-source.md](docs/building-from-source.md). Before opening a pull request run `cargo fmt --all --check`, `cargo test --workspace` and `cargo build --release --locked`.
* **Commit messages**: reference the issue, for example `Fixes #12`.

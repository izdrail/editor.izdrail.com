# Go to Test

"Go to Test" in the command palette lists the test files and test cases under `tests/` and opens the one you pick. Run it from the terminal with "Run Test at Cursor" / "Run Test File".

- `test-file  tests/Feature/UserTest.php`: opens the file.
- `test  UserTest::test_can_login`: a PHPUnit method named `test*`, or marked `#[Test]` or `@test`.
- `test  pest: it works`: a Pest `it('works')` or `test('works')` call at the start of a line.

Files named `*Test.php`, `*Spec.php`, `*-test.php` or `*.test.php` are always listed. Other PHP files under `tests/` are listed only if they contain test cases. `vendor` and `node_modules` folders are skipped.

Limits: static text scan, nothing is run. Tests generated by data providers show once. Pest `describe()` groups are not listed as groups, and `it()` calls indented inside them are not found. Methods with the `#[Test]` attribute must have it on the line directly above (blank lines and other attributes are fine). Depth 6, 1500 files, 1 MB per file, 5000 entries, symlinks skipped.

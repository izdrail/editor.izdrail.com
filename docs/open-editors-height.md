# Open Editors section height (item 328)

The Open Editors section had a fixed 150px height, which showed about 4 rows and then a scrollbar even with 17 files open. It is now 230px (about 8 rows plus the group header). The File Explorer section below keeps the remaining space. It is a fixed height, not proportional, so on a very short window the explorer gets less room.

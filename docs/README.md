# Gravity Editor user guide

Start here for everyday use. This guide describes the shipped editor, not every feature of the editors its keymap presets resemble.

- [Getting started](usage/getting-started.md): open a workspace, find files, save and search.
- [Shortcuts and keymaps](usage/shortcuts.md): common actions, compact keyboards, modal editing and custom bindings.
- [Full shortcut reference](usage/shortcut-reference.md): shipped keys, commands, modes and conditions for every preset.
- [Completion and keywords](usage/completion.md): Ctrl+Space, Laravel facades, snippets and AI suggestions.
- [Snippet prefix reference](usage/snippet-reference.md): all bundled expansion keywords by language/framework.
- [Agent chat basics](usage/agent-chat.md): draft starters, modes, attached context and sending.
- [Saved chat previews](usage/saved-chats.md): workspace history previews without resuming tools or changing your draft.
- [Local model setup](usage/local-model-setup.md): pending-only Ollama, LM Studio and on-device choices.
- [Mouse and location history](usage/mouse-navigation.md): Back/Forward side buttons, file and cursor history.

The rest of this folder contains focused feature notes and engineering history. Some older notes describe an earlier milestone or an unverified platform. They are not a promise that an external service is configured or available.

The current shortcut reference is derived from the actual `defaults/` files. Personal keymaps, the selected preset, editing mode, popup focus, OS-reserved keys and available language servers can change what a key does. The Keyboard Shortcuts screen is the place to check your active configuration.

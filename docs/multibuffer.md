# Editable diagnostics excerpts (preview)

Open the command palette and run **Diagnostics: Open Editable Excerpts (Preview)**. The existing **Diagnostics: Open Project Diagnostics Document** remains the read-only summary.

The preview gathers two lines of source context around each diagnostic and merges overlapping windows. File headers separate sources in one editor view. Typing, deletion, selection edits and undo/redo update the same source buffers used by ordinary editor tabs and language servers. Clearing a diagnostic does not remove the active excerpt while you type. Headers and edits crossing excerpt boundaries are rejected.

**Save** saves the underlying source buffers, not the projection text. Source tabs stay confirmed so normal workspace recovery and source close warnings retain them. The preview's dirty state follows its source buffers. An unsaved preview offers **Save Source Buffers** or **Keep Editing** when closed. Save As cannot write the aggregate text as a source file.

If a source changes independently, the stale preview refuses further edits and saves. Reopen the preview to refresh it. Closing or reopening a source under the same path does not let the old preview target a different buffer.

## Preview limits

- Excerpts reuse their source file's current lexer colors. Headers remain plain text. The gutter shows absolute source line numbers, with blank headers and separators. Go to Definition maps the caret to the canonical source before using the existing framework/LSP resolvers. Headers and stale sources do not issue definition requests; late responses are ignored after the source or caret changes. Find References, Go to Implementation and Call Hierarchy also use canonical source coordinates and reject stale asynchronous responses. Source diagnostic messages appear through the existing error lens settings and update with source diagnostics. F8 and Shift+F8 start from the canonical source position before opening the next or previous diagnostic. Headers and stale excerpts do not fall back to an unrelated diagnostic. They are display-only, not saved text. Hover uses canonical source text and positions for existing framework help and LSP requests, while keeping the tooltip anchored to the displayed excerpt. Headers and stale sources do not issue hover requests; late responses after source, projection or caret changes are ignored. Rename uses canonical source coordinates and places its input at the displayed excerpt. Prepared symbol ranges must stay inside that excerpt. Headers, stale sources and delayed results after source, caret or active-editor changes are refused. Confirmed rename uses the existing workspace-edit path, opens the canonical source and leaves the old excerpt stale; reopen the preview to refresh it. Dedicated diagnostic message rows and further source-aware LSP actions are not implemented in this preview. Stale or reopened source buffers are not painted with old source colors.
- Native compound operations compose sequential deltas while checking each intermediate step against protected headers. Disjoint edits retain their source boundaries instead of flattening across headers. Automatic pair insertion, closing-character skip and selection surround follow the existing editor settings, with header and source-boundary guards. Return and Tab use the canonical source buffer's indentation style, including detected tabs/spaces and .editorconfig overrides. Return uses the native editor's unmatched-pair indentation. A single action across sources with different indentation styles is refused; edit those sources separately. PHP `/**` followed by Tab uses the same canonical-source lexer check and single-step docblock expansion as ordinary source tabs. Comment toggle uses each canonical source's existing lexer-aware delimiter resolver, including mixed-content regions. Selections spanning headers or incompatible comment regions are not partially changed. Modal delete, yank, indent and outdent operators now use guarded native motions. Their complete line-expanded range must stay inside one excerpt; refused operations do not replace the yank register. Indent and outdent use the canonical source indentation style. Vertical motions at an unterminated excerpt end are refused rather than consuming the synthetic separator. Closing-bracket indentation resolves the opening delimiter in the complete canonical source, including an opener outside the excerpt, using the source editor existing syntax resolver. Each caret keeps its source indentation, and disabled automatic pairs do not align closers. IME preedit uses a projection-local overlay, never the source tab composition or saved text. Commit uses the guarded source edit path, with one selection inside a current excerpt. A changed source, projection or selection refuses the pending composition; restart it in the refreshed excerpt. Headers and multi-cursor composition are refused. Native composition acceptance is checked with a temporary IBus test engine; platform and engine-specific behavior is not full parity.
- The projection can include at most 128 files, with a 4 MiB per-file snapshot limit, a 16 MiB combined source budget and a 4 MiB projection budget. Each file can supply at most 1,024 diagnostic ranges. Oversized inputs stop with a message instead of opening a partial editable view.
- Source loading times out after 15 seconds. A save that is not confirmed within 30 seconds reports that fact and leaves the buffers open. Do not treat the timeout as a confirmed save or a confirmed failure; check the source buffers and retry when ready.

This is an early slice of the editable diagnostics multibuffer, not full parity with Zed's multibuffer.

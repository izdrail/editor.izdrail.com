# `<livewire:` tag completion (item 337)

In a `.blade.php` file, typing `<livewire:` lists the project's Livewire components: view files under `resources/views/livewire` and classes under `app/Livewire` and `app/Http/Livewire`, dotted and kebab-cased (`Admin/UserProfile.php` -> `admin.user-profile`). Go-to-definition on the tag already resolved these names. Other files get no items.

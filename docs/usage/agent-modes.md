# Agent mode and context card

The card above the composer explains the selected mode and the file or selection attached when you send. It changes with Chat, Ask, Plan, Act and external-agent modes. It is a description, not a permission grant or a connection test.

Chat does not run the project tool loop. Ask reads/searches. Plan can also save its plan artifact. Act proposes source edits for review; commands and MCP calls still need per-call approval. External agents own their runtime permissions and remain separate from native review. AI off is shown before any mode description.

Saved chats are read-only previews in this workspace. The separate External agents list contains ACP sessions. Neither label changes existing permissions, selected models or saved credentials.

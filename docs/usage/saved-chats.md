# Saved chat previews

Open the Agent panel, then **Saved chats - browse this workspace**. Click a title to read a plain-text preview of its last six saved turns. The browser shows at most the newest 20 readable sessions from this workspace only. Click the heading again to hide it; reopening refreshes the list.

This is a preview, not a resume action. It does not change your current conversation, draft, model, mode, project-read trust, reviewed edits or tool approvals. A saved Running state describes the old record, not an active run. Previewing never contacts a model or starts a tool. It is safe to browse while a current response is running.

History depends on the existing Save History setting. Unsaved turns are not included. File context bodies are not saved with these turns. Previews can omit earlier turns and shorten long messages; they are not a full transcript export. Use **Export walkthrough** for the current conversation.

External ACP sessions remain in the separate **Agents** list. Their resume controls are separate from these native saved chat previews. Selecting a native preview does not resume an ACP agent.

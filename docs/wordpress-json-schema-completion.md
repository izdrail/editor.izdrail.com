# WordPress theme.json and block.json schema completion (item 444)

Completes keys and enum values inside `theme.json` and `block.json` files
from a generated pack of the pinned WordPress JSON schemas.

## Data

`metadata/web/wp-json-schemas.json`, generated by
`scripts/generate-wp-json-schemas.py` from the pinned Gutenberg checkout
(schemas/json/theme.json, schemas/json/block.json; commit and SHA-256 in
`metadata/web/manifest.json`). The pack carries facts only - key paths,
value types and enum values; GPL schema prose is not copied. Doc links in
the pack point at the official theme.json / block metadata references.

Schema flattening resolves local `$ref`s and unions `allOf`/`anyOf`/
`oneOf`/`then`/`else` branches, collapses per-block settings/styles to a
`*` wildcard (they share one shape across core blocks), skips `@media`
breakpoint variants (they mirror the full styles shape) and prunes
nested pseudo-selector subtrees, then caps paths at seven segments
(deeper leaves are not completed by hand). Arrays complete through the
`*` item segment.

## Behaviour

- Key position: offers the schema's child keys at the cursor's object
  path, with the value types as the item detail.
- Value position: offers the key's enum values.
- Completion opens on the bare quote and after the colon (no typed
  prefix needed), like the other project completions.

## Tests

`project_completion::tests::wp_json_schema_completes_keys_and_enum_values`
covers root keys, nested keys, array-item keys and enum values.
